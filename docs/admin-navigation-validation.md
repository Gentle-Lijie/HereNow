# 后台统一导航验收

2026-10-14。后台将左侧侧栏与顶部栏合并为单一顶部导航，集中展示品牌、活动工作台、管理员创建入口、账号与退出。删除工作空间装饰、重复面包屑、日期、侧栏遮罩和展开按钮。页面内容使用完整可用宽度；窄屏在同一顶部区域内换行，导航／退出点击高度至少 44 px，长账号名截断并提供完整名称提示。

实施前查询 Ant Design MCP 的 Layout 文档与 Token，核对 Ant Design Vue 4.2.6 ConfigProvider 官方文档；保留现有 Vue 主题配置，导航使用原生语义元素与 RouterLink。

## 验证

- 类型检查、ESLint、代码格式检查、前后端构建与 `git diff --check` 通过。
- 使用实际构建产物、本机 MySQL 测试库 `herenow_test`、临时管理员和现场操作员账号；未创建或更改用户实际活动。
- Chrome 155、Edge 137 各通过 26 项浏览器断言：只有一个后台导航；侧栏／遮罩／展开按钮移除；320、375、390、430、768、1024、1440 px 无页面横向溢出，导航目标不少于 44 px；白色背景和长账号截断；工作台／创建入口高亮、跳转、刷新保持；键盘焦点与 Tab 顺序；操作员不显示创建入口；退出后后台跳转登录；无页面运行时错误。
- 复核 320、390、1440 px 工作台及 390 px 创建页截图。截图与诊断脚本位于忽略目录 `output/playwright/`。

本次为后台导航布局验收，没有执行手机真机、扫码、现场定位或性能验收，不能作为 Spec 第 15 节全部验收通过的依据。
