## 实现与兼容

1. 范围外保留原提示，增加由后端计算的 `ceil(d - R)` 米，表示到围栏边界的近似直线距离。精度不足、边界不确定、坐标来源与转换失败的判断不变；失败不消费会话，可以重新定位提交。
2. `checkin_early_minutes` 为 0–1440 的整数，默认 0。共享开放时间计算用于后台、动态码、建会话、线上提交与人工补签；活动开始时间仍独立显示。修改提前分钟数增加 policy_epoch，旧未完成会话失效，已成功幂等结果仍可读取。迁移 004 回填旧活动为 0。
3. 上传活动 Logo 后等比压缩 PNG，后端验证实际内容、CRC、大小与尺寸，重编码后存入活动 JSON；没有原图文件或外部图片请求。输入 PNG / JPEG / WebP 最大 2 MB；持久化 PNG ≤24 KiB、≤360×96。参与端新扫码会话和结果页使用活动 Logo，其他使用面不变；未配置或加载失败回退默认。纯展示修改不增加准入版本，旧会话沿用原展示快照；迁移 005 回填旧活动为 null。
