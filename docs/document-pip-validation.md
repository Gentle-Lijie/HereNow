# Document PiP 签到码

日期：2026-10-14。工作台和签到记录页的所有展示按钮统一使用 Document Picture-in-Picture API，在原始点击任务内先申请窗口，再授权与懒加载。保留 Logo、活动名称、“签到”、二维码和倒计时；旧 display URL 复用相同内容。2026-10-15 按用户补充要求，PiP 另加入中文／English 切换按钮，复用并记住共享语言选择；按钮样式随组件复制到浮窗，窄窗时头部允许换行。

窗口关闭、活动切换和原页面关闭清理 Vue 组件、样式、事件、定时器；组件请求可中止，计时器绑定 PiP window。重复打开同一活动只聚焦现有窗口。仍使用原后台显示会话与 Cookie，凭证只经 POST 交换，不导航 PiP 窗口或把凭证写入查询；二维码在本地生成，按后端到期时间隐藏，不延长有效期。

类型、lint、构建与 5 项生命周期测试通过，覆盖用户手势调用顺序、不支持 API、授权期间关闭、跨活动替换及授权失败关闭空窗口。参照 Chrome 官方 Document PiP 文档，实际支持范围取决于安全上下文与桌面浏览器；网站不能去掉浏览器自身窗口框架。

按用户要求未使用 browser use，原生窗口、后台计时、窗口大小和扫码距离尚未通过真实浏览器／真机验收。上述单元测试不代表原生 API 兼容性实测。
