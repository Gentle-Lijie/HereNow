# 签到字段文字裁剪修复

日期：2026-10-14。按用户截图检查 Vant 4.10.2 Field / Cell 的实际样式及官方源码，修改仅限参与端字段样式。

输入控件原来仅设置最小高度、仍为零内边距；单元格与部分值容器带有 overflow 裁剪。本次对标签明确相对行高和上下留白；原生输入与文本域使用自动高度、8 px 上下内边距，输入和占位文字沿用同一行高。解除字段内部单元格／值／body 的裁剪，保留外层圆角边框；日期输入保持至少 44 px 高，多行输入保持至少 72 px 高，输入字号仍为 16 px。没有调整业务校验、定位或表单提交规则。

严格类型、lint、前端生产构建、格式检查通过。遵守用户不使用 browser use 的要求，没有执行浏览器截图与真机验收；页面缩放、系统字体放大、移动浏览器及键盘状态下的实际效果仍需实测，不能由构建成功代替。
