# 实施与验收记录

日期：2026-10-14。版本：核心开发版 v0.1.0。依据：Spec v1.4（基础验收记录保留原测试时结果）。此次完成可运行的主要业务闭环，尚未达到 Spec 全部 P0 的生产验收条件。

## 已实现

- npm 单仓库 workspace、Vue 3 / TypeScript / Vite、按路由拆包的后台、参与端与独立展示页。
- Ant Design Vue 后台、Vant 手机表单、桌面与手机记录布局、空状态、异常提示及安全区。
- 后台 Argon2 密码摘要、数据库会话、管理员 / 受活动授权的操作员；后台无公开注册。
- 活动草稿、发布、暂停、恢复、关闭；自定义字段、开放 / 名单准入、固定身份规范化、字段版本与 policy_epoch。
- CSV / XLSX 模板、映射、工作表选择、预览、错误报告与整批提交；前导零、重复、公式、外部链接及解压限制。
- 授权展示会话、30 秒刷新 / 45 秒有效的签名活动码、120 秒不滑动续期的浏览器绑定提交会话。
- 后端字段、活动、身份、名单、位置与权限校验；InnoDB 唯一约束、锁顺序与事务中的会话消费 / 幂等记录。
- 网络结果不确定时保留原请求与幂等键；刷新页面仍可确认原结果。暂存提交快照仅在本标签页 sessionStorage 保存，最长 30 分钟，成功或明确失败后删除。
- 标准 Geolocation、后端 WGS84 标准化与 gcoord 适配、精度 / 距离 / 边界判断；强制失败不自动成功。
- 地图 SDK 按需加载、POI / 点击 / 拖动 / 圆形围栏的接口接入、确认 / 取消与明确坐标系备用录入。真实地图服务尚未验收，见下方限制。
- 人工成功 / 待核验补签、确认、撤销、恢复、审计记录、当前状态回执与 XLSX 字符串导出。
- AES-GCM 风险证据、浏览器带密钥摘要、直接连接 IP / 明确信任代理配置、CSRF / Origin 检查、基础限速、禁止名单公开查询与凭证缓存。
- 迁移、管理员初始化、操作员创建与活动授权、保留期清理、备份、隔离恢复验证与删除账本重放工具。

## 管理员密码配置

`ADMIN_PASSWORD` 是首次创建账号的初始密码；登录接口校验数据库中的 Argon2 摘要。修改 `.env` 不会自动覆盖已有账号。新增 `npm run admin:reset-password`，由部署方显式将配置密码更新到指定管理员，并撤销旧会话、记录不含密码的审计。已验证新密码登录、旧密码拒绝、旧会话失效，以及拒绝空密码、缺失管理员和操作员提权。
