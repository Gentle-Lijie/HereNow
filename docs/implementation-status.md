# 实施与验收记录

日期：2026-10-14。版本：核心开发版 v0.1.0。依据：Spec v1.3。此次完成可运行的主要业务闭环，尚未达到 Spec 全部 P0 的生产验收条件。

## 已实现

- npm 单仓库 workspace、Vue 3 / TypeScript / Vite、按路由拆包的后台、参与端与独立展示页。
- Ant Design Vue 后台、Vant 手机表单、桌面与手机记录布局、空状态、异常提示及安全区。
- 后台 Argon2 密码摘要、数据库会话、管理员 / 受活动授权的操作员；后台无公开注册。
- 活动草稿、发布、暂停、恢复、关闭；自定义字段、开放 / 名单准入、固定身份规范化、字段版本与 policy_epoch。
- CSV / XLSX 模板、映射、工作表选择、预览、错误报告与整批提交；前导零、重复、公式、外部链接及解压限制。
- 授权展示会话、30 秒刷新 / 45 秒有效的签名活动码、120 秒不滑动续期的浏览器绑定提交会话。
- 后端字段、活动、身份、名单、位置与权限校验；InnoDB 唯一约束、锁顺序与事务中的会话消费 / 幂等记录。
- 网络结果不确定时保留原请求与幂等键；刷新页面仍可确认原结果。暂存提交快照仅在本标签页 sessionStorage 保存，最长 30 分钟，成功或明确失败后删除。
- 标准 Geolocation、后端 WGS84 标准化与 gcoord 适配、精度 / 距离 / 边界判断；强制失败不自动成功。
- 地图 SDK 按需加载、POI / 点击 / 拖动 / 圆形围栏的接口接入、确认 / 取消与明确坐标系备用录入。真实地图服务尚未验收，见下方限制。
- 人工成功 / 待核验补签、确认、撤销、恢复、审计记录、当前状态回执与 XLSX 字符串导出。
- AES-GCM 风险证据、浏览器带密钥摘要、直接连接 IP / 明确信任代理配置、CSRF / Origin 检查、基础限速、禁止名单公开查询与凭证缓存。
- 迁移、管理员初始化、操作员创建与活动授权、保留期清理、备份、隔离恢复验证与删除账本重放工具。

## 开发启动修复

2026-10-14：修复 Vite 先监听、API 尚未初始化完成导致 `/api/context` 连接被拒绝的启动竞态。Vite 在实际 API 健康检查成功后才开始监听，等待最多 60 秒；代理读取 `PORT`，前端地址与端口读取 `APP_ORIGIN`，端口占用时明确退出。API 在发布监听地址前检查数据库连接。

## 尚未完成或实测

1. **地图授权**：当前缺高德 Key；真正 POI 搜索、点击、拖动、围栏预览及官方安全代理须配置授权后验证。备用录入不能替代此 P0 验收。
2. **真机**：尚未验证 iOS Safari、微信内置浏览器、安卓实机的二维码跳转、Cookie、定位、精度、软键盘与权限路径；桌面 Chromium 不能替代这些结论。
3. **坐标与地域**：官方参考点比对、现场转换预算与已支持地区验证仍待完成；不宣称实际转换误差已满足 5 m 目标。高德定位 SDK 回退目前未启用，首期使用标准 Geolocation。
4. **数据库版本**：DDL 采用 MySQL 8.4 可用能力；此次因用户指定使用本机实例，实际运行和集成测试为 9.3.0，未在 8.4 实测。
5. **生产运维**：未部署生产环境。TLS、实际可信入口、代理头覆盖、生产压测混合流量、告警、每日备份 / 周期清理调度及任务互斥尚需部署配置。当前工具手动可运行。
6. **管理完整性**：展示会话当前到期 / 活动结束失效，尚无单独撤销界面；原始风险证据查看与额外权限界面未开放，默认不可读取原始证据。完整审计浏览界面尚未实现，已有受权限保护的审计 API。
7. **额外验收**：完整 200% 缩放、横竖屏与触控矩阵、保留期自动清理 / 恢复后删除重放演练、浏览器存储完全关闭的体验及生产资源条件下的持续峰值验证仍待完成。

上述项目完成前，定位、性能、备份与兼容性不能描述为已达到生产验收；P1 / P2 功能未展开。
