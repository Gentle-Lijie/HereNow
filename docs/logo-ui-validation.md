# Logo 与签到信息 UI 修复

日期：2026-10-14。依据用户截图与 Spec 4.2；三项修复分别提交。

- 签到时间、地点的 SVG 与文本使用明确文本容器，flex 垂直居中、20 px 行高；移除图标顶部补偿，保留长文本换行。
- 电子码展示页复用 EventBrand，读取当前活动 Logo。经过有效展示会话或后台活动授权的 `/api/display/events/:id/info` 仅返回名称、地点和 Logo；已暂停时仍保留品牌。展示会话过期后，有该活动权限的后台账号可读取品牌资料，但不能因此取得新的二维码。二维码接口继续独立验证有效展示会话及活动状态／时间，匿名和无授权操作员不能读取元数据。
- Logo 选择区改为独立预览框、上传／替换与恢复默认操作、格式提示；窄屏纵向排列，按钮至少 44 px 高。Ant Design Vue Form 的 `input[type=file] { display:block }` 覆盖了 hidden 属性的浏览器样式，改用 Vue v-show 的内联 display:none，原生选择文件按钮不再占用布局；真实文件输入保留以支持手动触发系统选择器。

验证：严格类型、lint、格式检查及前后端生产构建通过；服务器独立真实 MySQL 8.4.5 上全量 79 项测试通过。覆盖展示会话和后台活动授权、匿名／无活动授权拒绝、暂停仍返回 Logo、二维码仍拒绝，以及纯展示资料不泄露名单和凭证。生产 HTTPS 读取活动 2 的展示资料与后台配置，确认 Logo 一致，未改动真实活动数据。

遵守用户不使用 browser use 的要求，本次未执行浏览器截图、点击及真机检查；布局和图片选择的视觉／交互效果仍需实际验证，不能把代码和 HTTP 检查当作视觉验收通过。
