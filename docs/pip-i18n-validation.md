# PiP 后的参与端中英文支持

日期：2026-10-14。按用户顺序，先单独提交 Document PiP，再单独实现双语。

范围：/display、/s 的固定界面、字段标签、输入提示、定位状态、错误反馈、签到状态与保存凭证支持中文／English。使用内嵌字符串，不新增 JSON 文案文件；语言由浏览器偏好初始化，用户可切换并记住偏好。PiP 保留 Logo、活动名、签到、二维码和倒计时，2026-10-15 按用户补充要求加入中文／English 按钮，跟随并可修改同一语言设置。

字段配置 label 与 label_en 必填。严格输入 schema 和发布接口校验双语名称；历史读取与编辑草稿使用兼容 schema。迁移 006 在活动行锁事务中加入空英文名，不自动猜测翻译、不改答案、旧表单快照或准入版本。旧活动保持运行，编辑保存／发布需补齐英文名称；已有会话和幂等恢复保持。用户配置的活动名、说明、选项文字和实际回答不自动翻译。

实际通过：类型、lint、格式、前后端构建；本地与服务器独立真实 MySQL 8.4.5 全量 92 项测试。覆盖 PiP 调用顺序和清理、切换文字与标签、英文字段必填、旧配置读取与活动迁移、旧活动继续提交和翻译不失效规则、英文围栏距离、凭证标签／布尔值／空值。参与入口 JS gzip 115.3 KB，通过 250 KB 预算。

生产先备份后执行迁移 006，后端切换到 20261014-i18n。HTTPS 验证缺英文名请求拒绝、双语名保存与返回、旧活动读取通过，临时验证活动已清理。按用户要求未使用 browser use；原生 PiP、实际语言按钮与手机视觉／定位尚未通过浏览器／真机验收，模拟窗口测试不能代替原生 API 实测。
