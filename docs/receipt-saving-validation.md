# 签到凭证保存与填写信息展示

日期：2026-10-14。依据用户要求及 Spec 9.5，改动限参与端展示与纯格式化函数。

- 仅 CHECKED_IN 状态显示截图保存提示；内容较长时提示使用长截图。待核验和撤销仍显示真实状态，不提示保存成功凭证。
- 签到时间按活动时区使用 YYYY/MM/DD HH:mm（24 小时制），午夜为 00:00；其他页面的简略时间格式不变。
- 按第一页表单顺序显示全部公开用户填写字段，数据使用已保存的 result.answers；刷新、回执查询或成功幂等恢复继续读取后端回答快照，不依赖已删除的表单草稿。
- 单选／多选显示选项文字，布尔值显示是／否；0、false 和文本编号前导零保留，多行文本保留换行。空的可选字段显示未填写。后台字段、名单来源字段、未知回答键不加入填写信息；页面只使用 Vue 文本插值，长文字可完整换行。

验证：类型、lint、格式、前端生产构建通过；3 项新增测试覆盖时区跨年／午夜、完整字段顺序和值转换、选项文字以及隐藏字段过滤。参与端首屏及静态依赖 JS gzip 112 KB，通过 250 KB 预算。没有修改 API 权限、事务或数据库结构。按用户不使用 browser use 的要求，未执行截图保存的浏览器交互与真机视觉验收。
