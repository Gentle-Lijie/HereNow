# 界面精简与自动验收

日期：2026-10-14。对应 Spec 第 4.2、4.4、10.5、15 节。本次只调整界面与显示文案，业务校验沿用原有后端服务。

## 改动

- 登录、后台、扫码签到、二维码展示与不存在页面统一纯白背景。
- Ant Design Vue 按钮、原生 SVG 按钮的图标与文字使用同一居中轴，覆盖前置、后置与加载图标。
- 减小后台导航、标题、卡片、表单与列表间距；移除登录故事区、活动装饰封面、侧栏宣传区、重复创建入口及宣传标语。编辑页卡片按内容高度排列。
- 扫码签到保留活动名称、起止时间、地点、管理员设置的说明、必要字段、按需定位、隐私同意、提交与回执。移除装饰文案、重复标题、装饰图案及提交箭头，保留会话过期、重试和审核状态说明。
- 手机输入字体维持至少 16 px，签到输入与按钮保留至少 44 px 的操作高度，保留底部安全区。

## 检查方式与结果

使用本机真实 MySQL 的 `herenow_test` 测试库、独立临时管理员与活动，隔离预览运行在 `http://localhost:5174`。Playwright CLI 使用 Chromium 实际渲染构建产物，结合 DOM 检查与截图复核；没有增加镜像实现的外观单元测试。

- `npm run typecheck`、`npm run lint`、`npm run test`、`npm run build`、`npm run check:bundle`、前端 Prettier 检查与 `git diff --check` 通过。现有 4 个测试文件、36 项测试全部通过，包含真实 MySQL 事务与幂等回归。
- 活动工作台、创建／编辑活动、名单、记录及不存在页面在 320、375、390、430、768、1,024、1,440 px 检查，42 组布局没有页面横向溢出，带文字的 SVG 按钮中心偏差不超过 1 px。390 与 1,440 px 截图复核通过。
- 登录、扫码签到与展示页在相同 7 种宽度检查纯白背景、布局和二维码可见区域，截图复核通过。手机签到输入字号及提交按钮高度满足上述约束。
- 真实 API 闭环：后台登录与字段错误；扫码建会话及清除 fragment；单选、多选；必填错误；缺少隐私同意拒绝；成功提交与刷新恢复回执。
- 模拟丢失一次已成功提交的响应：刷新后通过原幂等键及原请求体重试，取回同一成功结果。
- 浏览器模拟定位：记录模式拒绝定位仍可提交，强制模式缺少位置被阻止，模拟围栏内坐标可成功；参与端没有加载后台路由或地图脚本。
- 展示端断网并推进浏览器时钟：过期码隐藏，恢复连接后换新码；移动导航及按钮加载状态另行复核。
- 参与端入口及静态依赖 gzip 总量约 109.6 KB，低于 250 KB 预算。

浏览器脚本、检查日志和截图保存在忽略目录 `output/playwright/`，临时测试账号与活动在结束时清理。验收中使用的坐标、权限拒绝和网络失败均为浏览器自动化模拟。

## 未验证范围

本次通过桌面 Chromium 自动验收，未进行 iOS Safari、微信内置浏览器、安卓真机扫码与定位，未实测软键盘、设备安全区、200% 浏览器缩放、真实高德服务及现场定位精度，未重新进行生产负载与性能验收。这些不能视为 Spec 第 15 节全部验收通过。
